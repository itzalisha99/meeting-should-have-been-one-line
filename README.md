The single sentence that could have replaced an entire pointless meeting:

> The decision is already in the invite description, so this meeting ended before it started.

The decision was already written down before anyone sat down — the meeting ended before it started. Built for the [make.fun bounty](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c).

## How it works

`main.py` writes the line to `/output/entry.txt` and reads it back to confirm the file is byte-identical to the entry. A `validate()` gate mirrors the bounty gate (1–200 characters, UTF-8, not only whitespace, a single line) and rejects anything the sealed scorer would mark invalid before a byte is written.
